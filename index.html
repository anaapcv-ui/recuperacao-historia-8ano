🔧 Como usar este material

  1. Comece pelo Diagnóstico para saber exatamente onde perdeu ponto.
  2. Vá para o Resumo de Revisão e estude as fichas — as de borda vermelha são as mais importantes.
  3. Faça o Simulado com calma, como se fosse a prova de verdade.
  4. Ao terminar, clique em Finalizar: o material gera um código de liberação e mostra quantas você acertou.
  5. Digite o código para abrir o gabarito comentado e entender cada resposta.

💾 Tudo o que você escrever fica salvo sozinho neste computador. Dá para fechar e voltar depois.

👩 Recado para a mãe

No fim do simulado aparece um código no formato SIM-XX-YY. Os dois números do meio (XX) mostram quantas questões objetivas seu filho acertou — é um jeito rápido de acompanhar o desempenho.

As questões discursivas não entram na contagem automática: elas trazem uma resposta modelo para você comparar e corrigir junto.
